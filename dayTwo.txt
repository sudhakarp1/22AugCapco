Strings:
--------
commonly used methods of str class:
----------------------------------
	st.split()  ==> split string into a list of words by default.
	st.join(list) --> joins list into a string with st as separator.
	
	st.lower()  --> converts to lowercase
	st.upper()  --> converts to uppercase
	st.strip()  --> removes whitespace at the begining and end of the given string 
	st.find(sub) --> find and print the index of the sub string in the string [ returns -1 if not found ]
	st.replace(a, b) --> find sub-string 'a' and replace with 'b' in the given string 
	st.count(sub) --> counts the occurrence of sub-string sub

Object Oriented Programming Concepts:
-------------------------------------
	class Name:
		data = 10 #class data 
		def methodOne(self):
			print()
			
		def methodTwo(self, a, b, *arg, **kwargs):
			pass 
		

	obj = Name()		
	a = Name()
	
	obj.methodOne()
	obj.methodTwo(10,20)
	
	a.methodOne()
	a.methodTwo(100,200)
	
============================================
Even though we talk about encapsulation, In Normal OOP language we use keywords like private, protected to achieve this. 

We do not have such provision in Python. But to enact the principle we do use certain naming convention.

	If your data or method's name starts with (double underscore)
		__var 
		__method(self, *args)
		
	It tries to achieve or mimic private member of the class 
	
	If your data or method's name starts with (single underscore)
		_var 
		_method(self, *args)
		
	It tries to achieve or mimic protected member of the class
